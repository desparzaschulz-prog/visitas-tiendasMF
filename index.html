Configuración de base de datos

Para que todo el equipo comparta el mismo repositorio, la app usa JSONBin.io como base de datos en la nube. Es gratuito y no requiere instalar nada.

  1. Entra a jsonbin.io y crea una cuenta gratis
  2. Ve a API Keys y copia tu Master Key
  3. Pégala aquí abajo y haz clic en "Conectar"
Sin configurar

Una vez configurado, todos los miembros del equipo que abran esta URL y usen la misma API Key verán los mismos datos en tiempo real.
